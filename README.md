# Песочница анимаций

## Как пользоваться

Экран состоит из двух частей:

- **Тулбар** (сверху, всегда виден) — служебный инструмент песочницы.
- **Макет** (под тулбаром) — точная копия экрана: шапка, сайдбар,
  таблица классов, сайдпейдж редактирования ученика, диалог сохранения.

### Два режима

Переключаются сегмент-контролом в левой части тулбара:

- **Просмотр** (по умолчанию) — макет работает как обычный интерфейс: строки
  раскрываются, сайдпейдж выезжает, диалог появляется — со всеми
  настроенными анимациями.
- **Выбор** — клики по макету не выполняют его действий, а выделяют элемент
  под курсором. У выделенного элемента в тулбаре открывается панель
  настройки анимации.

Чтобы настроить анимацию слоя, который по умолчанию скрыт (сайдпейдж,
диалог, строка встроенного добавления ученика), сначала откройте его в
режиме «Просмотр» обычным действием (например, кликом по карандашу в строке
ученика), затем переключитесь в режим «Выбор», не закрывая его, и кликните
по нему.

### Настройка анимации

После выбора элемента в панели под тулбаром — список слоёв перехода.
У элемента может быть несколько слоёв одновременно (например, сдвиг + плавное
появление). Для каждого слоя:

- **Вид перехода** — что именно анимируется (прозрачность, сдвиг, масштаб,
  поворот, цвет фона и т.д.). Один и тот же вид нельзя добавить дважды.
- **Изинг** — выбор из стандартных пресетов (заполняет поле `cubic-bezier`)
  либо ручной ввод значения.
- **Длительность** и **задержка** — в миллисекундах.

Все изменения применяются немедленно, без кнопки «Применить». Кнопка
«Проиграть» в тулбаре повторяет анимацию появления выбранного элемента.

### Где хранятся настройки

В `localStorage` браузера. Настройки переживают
перезагрузку страницы. Кнопка «Сбросить всё» в тулбаре (с подтверждением)
полностью очищает их — макет возвращается к состоянию без анимаций.

### Как выгрузить настройки

Кнопка «Параметры» в тулбаре открывает список всех применённых настроек в
двух форматах — **JSON** (для повторного использования/передачи) и **CSS**
(готовые правила `transition`, сгруппированные по разделам макета). Кнопка
«Скопировать» копирует текущую вкладку в буфер обмена.

### Иконка сворачивания сайдбара

В кнопке восстановлена исходная залитая иконка. В режиме «Выбор» клик по
иконке открывает её настройки; Alt+клик выбирает кнопку целиком.
«Проиграть» показывает сворачивание и обратное разворачивание сайдбара.

В общий список переходов добавлены «Отражение по горизонтали» и
«Отражение по вертикали». Длительность, изинг и задержка настраиваются
обычным способом, сохраняются в JSON и выгружаются в CSS. Масштаб и оба
отражения используют одно свойство `scale`, поэтому для элемента можно
выбрать только один из этих трёх видов перехода.

Без настройки отражения иконка меняет направление мгновенно по горизонтали.
Для вертикального отражения выбранная иконка симметрична, поэтому её
начальная и конечная формы совпадают, но промежуточное сжатие видно.
